# AI Video Editor

محرّر فيديو مكتبي حقيقي لـ Windows، مبني بـ Electron وReact/TypeScript، ومصمم ليعمل **محليًا أولًا**. ليس صفحة ويب تُفتح في Chrome. النسخة الحالية تتضمن مشاريع JSON ومراجع أصول دون نسخها تلقائيًا، استيراد وسائط ومعاينتها، قص/تقسيم/حذف غير تدميري، تحليلًا محليًا عبر FFmpeg، ووكيل تحرير Google Gemini اختياريًا بأدوات آمنة قابلة للتوسعة، إضافة إلى مسار موسيقى مستقل بموجة قابلة للمعاينة والمزج، ومحرر ترجمة يدوي، وخطة Shorts مرتبطة ببيانات تحليل حقيقية، مع Undo/Redo وتصدير فعلي.

> تفاصيل قرارات التصميم، حدود النسخة الحالية، مراحل التطوير، ومخطط البيانات في [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## المتطلبات

- Windows 10/11 x64 (التطوير ممكن على Linux/macOS أيضًا).
- Node.js 22.12 أو أحدث لتشغيل أدوات التطوير الحالية.
- لا يحتاج FFmpeg مثبتًا على النظام: يستخدم حزمتي `ffmpeg-static` و`ffprobe-static` المرفقتين عند تثبيت الاعتماديات، مع إمكانية تحديد مسارات بديلة عبر `FFMPEG_PATH` و`FFPROBE_PATH`.
- اختياري لتحويل الكلام إلى نص محليًا: `whisper.cpp` (`whisper-cli.exe`) وملف نموذج GGML تختارهما من الإعدادات.
- اختياري لتفعيل وكيل المونتاج Gemini: أدخل Google Gemini API Key بنفسك من Settings. يُشفّر المفتاح بواسطة `safeStorage` في Electron (على Windows عبر DPAPI) ويحفظ خارج `settings.json`؛ من دون مفتاح تبقى أدوات التحرير اليدوية والأوامر المحلية المحدودة متاحة.

## التشغيل والتطوير

```bash
npm install
npm run dev
```

فحوصات TypeScript والاختبارات:

```bash
npm run typecheck
npm test
npm run build
```

لاختبار مسار الوسائط الحقيقي باستخدام FFmpeg/FFprobe (ليس واجهة Electron E2E):

```bash
npm run test:media
```

يشغّل الاختباران الحقيقيان `mediaEngine.integration` و`editorJourney.integration`. ينشئان وسائط اصطناعية داخل مجلد مؤقت محايد للنظام، بأسماء عربية/Unicode ومسافات؛ ويمران عبر probe، thumbnail/waveform، التحليل المحلي، قص الفيديو والصوت، مزامنة مسار الموسيقى والترجمة عند إنشاء Short، ثم تصدير فعلي والتحقق من المدة والدقة ووجود ترددات الموسيقى وتوقيتها. رحلة المحرر تستخدم Electron dialogs وردود Gemini **مخططة/Mocked**، لكنها تستخدم ProjectStore وAgentToolRegistry وFFmpeg/FFprobe الفعليين. لا تُعد اختبارًا لعرض الواجهة أو تشغيل الفيديو في نافذة Electron.

يتطلب `FFmpeg` و`FFprobe` قابلين للتشغيل؛ يحاول الاختبار استخدام الحزم المرفقة ثم `PATH`، ويمكن تعيين `FFMPEG_PATH` و`FFPROBE_PATH` لمسارين كاملين. إذا لم تتوفرا يفشل `npm run test:media` برسالة واضحة؛ لا يتحول إلى Mock أو نجاح متخطٍ. أما `npm test` الاعتيادي فيتخطى هذين الاختبارين عمدًا.

لاختبار Agent مع طلب حي إلى Google Gemini (اختياري، ويرسل نص الطلب فقط دون وسائط):

```powershell
$env:GEMINI_API_KEY = 'ضع المفتاح محليًا في متغير البيئة'
npm run test:live-agent
```

هذا الاختبار يستدعي Google فعليًا؛ يتطلب اتصالًا ومفتاحًا صالحًا وقد يستهلك الحصة. المفتاح لا يُكتب بواسطة السكربت ولا يظهر في رسائل الاختبار. لا يشغّل واجهة Electron.

إنشاء مثبت Windows x64 بصيغة NSIS:

```powershell
npm run dist:win
```

يجب تشغيل الأمر على Windows x64: حزمة `ffmpeg-static` تحمل ثنائيًا خاصًا بنظام البناء، لذا يبدأ الأمر بفحص المنصة ووجود FFmpeg/FFprobe وElectron قبل أي بناء، ويمنع إنشاء مثبت Windows يحمل ثنائي Linux بالخطأ. ثم يشغّل فحوص النوع والاختبارات واختبار الوسائط والبناء، يبني NSIS، ويثبّت التطبيق بصمت لتشغيل فحص من النسخة المثبتة لمساري `app.asar.unpacked`.
يظهر المثبت في `release/`. يُجري التطبيق عند بدء التشغيل فحصًا فعليًا لـ`FFmpeg -version` و`FFprobe -version`؛ وإذا تعذّر أحدهما تظهر رسالة دائمة واضحة في الواجهة بدل الاعتماد الصامت على برنامج من `PATH`. لا يحتاج المستخدم النهائي إلى تثبيت FFmpeg أو FFprobe. جميع مقاطع الفيديو الأصلية تبقى في مواقعها؛ ملف المشروع يحتفظ بمراجع إليها ولا ينسخها تلقائيًا.

## أول تجربة

1. افتح Settings، أدخل مفتاح Google Gemini API، واحفظه ثم اختبر الاتصال. هذه الخطوة اختيارية؛ من دونها يظل التحرير التقليدي متاحًا.
2. أنشئ مشروعًا واختر مجلدًا له.
3. استورد ملف فيديو؛ تُقرأ بياناته ويُنشأ له thumbnail وموجة صوتية محليًا عند وجود صوت.
4. يبدأ تحليل الصمت/المشاهد/مستوى الصوت في الخلفية، ويمكن عرض النتائج من تبويب **النص والتحليل**.
5. مع إعداد Gemini، جرّب **«احذف فترات الصمت التي تزيد عن ثانية»**. يفحص الوكيل بيانات المشروع بالأدوات، ويحلّل محليًا عند الحاجة، ثم يعدّل Timeline دون تغيير الأصل.
6. استورد صوتًا إلى مسار الموسيقى المستقل؛ اسحب المقطع واضبط نقاط المصدر والكسب أو اكتم المسار. تُعاين الموسيقى مع التشغيل وتدخل في مزج FFmpeg عند التصدير.
7. استخدم محرر Subtitles لإضافة نص يدوي أو تعديل التفريغ والتوقيت أو الحذف. جميع التغييرات قابلة للتراجع وتظهر في المعاينة والتصدير.
8. مع تفريغ محلي فعلي، اطلب من Gemini اقتراح Shorts؛ تعتمد النتائج على كثافة النص وتغطيته وحدود المشاهد والصمت المحللة. اختيار مقطع قصير كبير يتطلب موافقتك، ولا يدّعي النظام فهم محتوى الصورة أو ضمان الانتشار.
9. استخدم تقسيم عند رأس التشغيل، أو اسحب مقبضي بداية/نهاية المقطع في الـTimeline (أو أدخل القيم من المفتش). القص غير تدميري ويُسجل كعملية واحدة قابلة للتراجع. جرّب التراجع والإعادة ثم صدّر MP4/MOV/WebM.

## حدود MVP بوضوح

- التحليل الصوتي وكشف الصمت/المشاهد، Timeline، التحرير الأساسي والتصدير عمليات فعلية وليست أزرارًا تجميلية.
- تفريغ الكلام يتطلب إعداد `whisper.cpp` ونموذجه محليًا؛ لا يُرفع الملف تلقائيًا لأي خدمة.
- Google Gemini هو مزود الذكاء النشط للوكيل عند إدخال المفتاح. المفتاح لا يظهر مجددًا بعد الحفظ، ولا يُسجّل في Logs أو `settings.json`. يُرسل نص الطلب فقط أولًا؛ ولا يطلب الوكيل من التطبيق إلا بيانات المشروع اللازمة عبر أدوات منفصلة. عند استدعاء transcript أو بيانات نصية، قد يُرسل ذلك السياق المحدد إلى Google. لا تُرفع ملفات الفيديو/الصوت تلقائيًا. كود Ollama القديم محفوظ لكنه غير مستخدم من واجهة الوكيل الحالية.
- من دون مفتاح Gemini، يظل المحرر والأدوات التقليدية عاملة، ويمكن تنفيذ بعض أوامر القص البسيطة محليًا؛ الأسئلة الحرة والتخطيط الذكي يتطلبان Gemini.
- الوكيل يملك أدوات حقيقية للسياق والتحليل المحلي، قص/تقسيم/نقل المقاطع، Undo/Redo، الموسيقى المستقلة ومزجها، وكابتشن/ترجمة Timeline. أداة Shorts ترتب المقاطع من transcript محلي مع بيانات المشاهد والصمت، ويمكنها تجهيز اقتطاع عمودي قابل للتراجع؛ الاقتطاعات الكبيرة تنتظر موافقة المستخدم. لا توجد بعد أوصاف بصرية للأشخاص/الأشياء أو Smart Crop/Tracking أو نصوص متحركة وانتقالات.
- المعاينة تعرض المقطع الحالي في المشروع، والتصدير يركّب ملفًا فعليًا بواسطة FFmpeg. طلب التصدير من Gemini يجهز الخيارات ويفتح نافذة التصدير للمراجعة؛ على المستخدم اختيار المسار والضغط على بدء التصدير.

## حالة التنفيذ والتحقق

| المسار | الحالة | الدليل/الحدود |
|---|---|---|
| Timeline وProjectStore وUndo/Redo | **Implemented · Tested** | اختبارات الوحدة الحالية ناجحة على Linux؛ الوسائط الأصلية تبقى مراجع ولا تُستبدل. |
| FFmpeg/FFprobe، القص والمزج والترجمة والتصدير | **Implemented · Requires FFmpeg · Untested here** | أضيف `npm run test:media` بوسائط حقيقية ومسارات Unicode؛ شُغّل هنا لكنه توقف عند غياب FFmpeg (FFprobe الثابت موجود ويعمل)، لذلك لم يحدث تصدير حقيقي. |
| رحلة الاستيراد→التحليل→Agent tools→Short→التصدير | **Implemented · Mocked Gemini/Electron dialogs · Requires FFmpeg** | اختبار مستوى الخدمة يستخدم ثنائيات فعلية عند توفرها، لكنه لا يشغّل نافذة Electron ولا يختبر مشغل المعاينة. |
| Gemini Agent وأدوات التحرير | **Implemented · Mocked in unit tests** | نجاح اختبارات الأدوات الوهمية لا يثبت اتصالًا حيًا. أضيف `npm run test:live-agent`؛ رُفض هنا قبل تشغيل Vitest لغياب متغير المفتاح ولم يُرسل طلب حي. **Requires Gemini**. |
| مثبّت Windows x64 وRuntime المرفق | **Windows-only · Untested here** | فحوص NSIS و`app.asar.unpacked` واختبار وسائط Windows مهيأة في `npm run dist:win` وCI؛ لم تُشغّل على Windows في هذه الجلسة. |
| واجهة Electron E2E ومعاينة التشغيل | **Untested** | لا يوجد عرض واجهة أو تحكم لاعب في اختبار الرحلة؛ فتح Electron هنا غير متاح. |
| Shorts candidates | **Experimental** | ترتيب بالأدلة النصية/الزمنية المحلية؛ ليس فهمًا بصريًا أو توقعًا للانتشار. |
| Visual Understanding وSmart Crop وText Layers وTransitions/Effects | **Not implemented** | لا يُدّعى وجود دعم فعلي لهذه الوظائف حاليًا. |
